Docker Containers

> 2 stack compose: monitoring (Uptime Kuma, Prometheus, Grafana) + sito/dev (code-server, FileBrowser)

IN_PRODUZIONE Ottobre 2026

Monitoraggio e ambiente di sviluppo del sito in container Docker sullo stesso host che serve queste pagine: Uptime Kuma per i check di disponibilità, Prometheus con exporter per le metriche, Grafana per le dashboard, code-server per modificare il sito dal browser e FileBrowser per gestire i file — con /var/www/html montato in bind dentro i container di sviluppo.

~2.4GB MEM_LIMIT

TECH_STACK

ARCHITETTURA

STACK monitoring (docker-compose, rete bridge di default)
  uptime-kuma :3001 ──► check HTTP/TCP dei servizi (dati: uptime_data)
  prometheus :9090 ──scrape──► node-exporter:9100 (metriche host, rete interna)
                           └─► blackbox:9115 (probe esterne, rete interna)
  grafana :3000 ──datasource──► prometheus:9090 (dati: grafana_data)
  config: /opt/monitoring/prometheus.yml montato in sola lettura
  probe attiva: blackbox http_2xx verso http://198.51.100.10/ (esempio; job blackbox-http)

STACK sito-dev (docker-compose, rete bridge di default)
  code-server :8444 ──► workspace = /var/www/html (bind, lettura-scrittura)
  filebrowser :8082 ──► /srv = /var/www/html (bind, lettura-scrittura)
